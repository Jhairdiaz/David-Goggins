# Página de la rutina

Fuente de la página publicada en https://claude.ai/artifact/BkVqYpoYEhUNBiRosEME5P

- `generar.py`: datos de cada sesión y ejercicio (carga, series, reps, RIR, descanso, tempo, última vez, siguiente paso).
- `plantilla.html`: diseño, semana y pestañas de Progresión y Día de partido.
- `img/`: fotos de referencia (Free Exercise DB, dominio público).

Para regenerar: `cd pagina && python3 generar.py` → crea `rutina.html` (no se versiona).
